# Mr. Yeung's Math Challenge

A modern, premium math question generator for Mr. Yeung's class.

## Features
- **MathsBot Clone**: Generates questions for Number, Algebra, Geometry, and Data.
- **Premium UI**: Dark mode, Glassmorphism, Neon accents.
- **Features**:
  - Countdown Timer with Sound Effects.
  - Student Roster with "Roast" and "Praise" generator.
  - Text-to-Speech integration.

## How to Run
```bash
npm run dev
```
